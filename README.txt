Teacher Digital Guide - backup
index.html : the page (open it in a browser; to host it, upload the whole folder keeping the structure).
docs/      : the PDF guides.
lib/       : PDF reader (pdf.js, Apache-2.0) used to view PDFs inside the page.
Note: opening index.html by double-click works for the page, but viewing PDFs inside the page needs the folder to be hosted (e.g. GitHub Pages / Netlify).
